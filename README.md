# 한영 변환기

한/영 키를 깜빡하고 친 글자를 어느 입력창에서나 바로잡아 주는 Windows 트레이 프로그램.

- `dkssudgktpdy` → `안녕하세요`, `ㅗ디ㅣㅐ` → `hello`
- 메모장, 브라우저, Word, 카톡 등 일반 입력창 어디서나 동작

## 기능

| 기능 | 사용법 |
|---|---|
| 단축키 변환 | **Ctrl+Space** — 마지막으로 한/영을 바꾼 뒤 친 내용 전체를 반대로 바꿈. 한 번 더 누르면 원래대로. 한/영 상태는 건드리지 않음 |
| 선택 영역 변환 | 텍스트를 드래그로 선택하고 Ctrl+Space |
| 자동 모드 | 스페이스, 문장부호(`. , ? ! ; :`), 닫는 괄호(`) ]`), Enter, 방향키로 단어가 끝날 때 (설정의 "로그인 칸 아이디 보호"를 켜면, 칸에 단어 하나만 치고 Enter를 누를 때 이름 같은 아이디는 그대로 둠) 방금 친 단어가 잘못 친 것 같으면 자동으로 변환. **Ctrl+Alt+Space** 또는 트레이 아이콘 클릭으로 켜고 끄기 |
| 대문자 유지 | 한글 모드에서 Shift로 친 영어(`Hello` → `ㅗ디ㅣㅐ`)도 변환하면 `Hello`로 대문자 그대로 (드래그 선택 변환은 소문자) |
| 자동 변환 취소 | 자동 변환 직후 **Ctrl+Space** → 원래대로 (Backspace는 평소처럼 한 글자 지움). 이렇게 되돌리거나, 바뀐 단어를 바로 지우고 똑같이 다시 친 단어는 그 창에서는 그대로 둠 (그걸 또 지우고 다시 치면 다시 바꿈) |
| 예외 단어 | 설정 창에서 자동 모드가 바꾸지 않을 단어를 직접 추가 (친 그대로 `rk`, 또는 바뀔 결과 `and` 어느 쪽이든) |
| 앱별 예외 | 설정 창 아래쪽에서 실행 중인 앱을 골라 추가하거나, 트레이 우클릭 → `<앱 이름> 앱 설정`에서 그 앱만 자동 모드/단축키 끄기 |
| 설정 | 시작 메뉴에서 한영 변환기를 **한 번 더 실행**하거나 트레이 아이콘 우클릭 → 설정… (단축키 변경, 예외 단어/앱 관리, Windows 시작 시 실행) |

트레이 아이콘이 파란색이면 자동 모드 켜짐, 회색이면 꺼짐.

### 변환 범위가 초기화되는 경우

마우스 클릭, 창 전환, 방향키·Home·End, Enter, 한/영 키, Ctrl/Alt 조합키. 이후 Ctrl+Space는 그 다음부터 친 내용만 바꿈.

### 자동 모드가 판단하는 방법

영어·한국어 단어 빈도 데이터(사전, 자막, 위키백과, 뉴스 등 7종 — [tools/DICTIONARIES.md](tools/DICTIONARIES.md))로 그 단어가 각 언어에서 얼마나 흔한지 비교해서, 확실할 때만 바꿈.

정확도: 사전에 쓰지 않은 뉴스·위키백과·웹 40만 문장으로 측정해서 멀쩡한 단어를 잘못 바꾸는 비율 0.001–0.006%, 잘못된 모드로 친 단어 복원 한국어 99.7%·영어 93–94%, 문장 통째 복원 한국어 98%·영어 89–92%(문장 맥락), 숫자+한글 99.8%. 실제 문장 6개짜리 긴 글은 단어 99.2–99.8% 복원, URL·이메일·약어 같은 예외 케이스를 섞은 자동 테스트 3만 문장에서 실패 23번(v0.5.5: 7,689번) — [정확도 분석 보고서](docs/accuracy-report.md)

- `내`(so), `해`(go)처럼 양쪽 다 말이 되는 건 그대로 둠 → 필요하면 Ctrl+Space
- 같은 문장에서 이미 고친 단어가 있으면 `to`, `a`, `I` 같은 짧은 단어도 같은 방향으로 바꿈 (문장 맥락 모드, 설정에서 끌 수 있음)
- 앞 단어 하나도 같이 고침: `to anfrjs` → `새 물건`, 따옴표 속 짧은 단어도 (`"dm" rufghs` → `"으" 결혼`), 한글 모드 `ㅑ ㅈ무ㅅ` → `I want` (단, `go to gkrry`처럼 영어 문장 속 `to`는 그대로)
- 영어 단어 + 조사·어미는 붙은 채로 고침: `signaldlftnfhr` → `signal일수록`, `stdrk` → `std가`, 띄어 친 조사도 (`std rk` → `std 가`), 대문자 한 글자 + 조사·낱말 (`Urk` → `U가`, `Avkxmqnxj` → `A파트부터`)
- 숫자·기호 옆: `0.4akszma` → `0.4만큼`, `$5fmf` → `$5를`, `5:22Rkwl` → `5:22까지`, 해시태그 `#aktwlq` → `#맛집`, 단어 앞 기호 `=rkrurql` → `=가격비`
- 한글 모드로 친 영어 표기: `company's`, `"I`, `a.m.`·`U.S.`·`Mr.` 같은 약어, 이메일·`www.` 주소, `snake_case`
- `ㅋㅋ`, `ㅠㅠ`, `ㅇㅋ` 같은 채팅 표현은 절대 안 바꿈
- 영어 모드에서 친 URL·이메일·@아이디, 기호가 섞인 비밀번호 같은 문자열, 대문자로 친 단어(`Hello`, `API`)는 한글로 안 바꿈
- 비밀번호 입력창에서는 아무것도 기록하지 않음

## 설치

[Releases](../../releases/latest)에서 하나를 받아 원하는 폴더에 두고 실행하면 끝. 설치 과정 없음.

| 파일 | 크기 | 설명 |
|---|---|---|
| `HanYeong-standalone.exe` | 약 77MB | **대부분 이걸 받으면 됨.** 아무것도 설치할 필요 없음 |
| `HanYeong.exe` | 약 6MB | [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)이 이미 깔려 있는 경우 |

- Windows 10/11 64비트
- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** (코드 서명이 없는 개인 프로젝트라서 뜨는 경고)
- 키보드 입력을 다루는 프로그램이라 일부 백신이 의심할 수 있음. 소스는 전부 이 저장소에 있음
- Windows 시작 시 자동 실행은 트레이 우클릭 → 설정에서 켜기

직접 빌드하려면 .NET 10 SDK 설치 후 `.\tools\publish.ps1` → `dist\`에 두 파일 생성.
이어서 `.\tools\install.ps1`을 실행하면 `%LOCALAPPDATA%\Programs\HanYeong`에 설치하고 시작 메뉴 바로가기, Windows 시작 시 실행까지 등록함 (관리자 권한 불필요, 다시 실행하면 업데이트).

## 알려진 제약

- **관리자 권한으로 실행된 창**에서는 동작 안 함 (Windows 보안 정책). 이 프로그램도 관리자 권한으로 실행하면 됨
- 안티치트가 있는 게임은 앱별 예외로 끄는 걸 권장
- VS Code처럼 Ctrl+Space를 쓰는 앱은 앱별 예외에서 단축키를 끄거나 설정에서 단축키 변경
- 자동완성이 글자를 바꿔 넣는 입력창에서는 지울 글자 수가 어긋날 수 있음

## 파일 위치

- 설정: `%APPDATA%\HanYeong\settings.json`
- 로그: `%LOCALAPPDATA%\HanYeong\hanyeong.log` (입력한 내용은 기록하지 않음 — 이벤트와 글자 수만)

## 개발

```powershell
dotnet test                                  # tests/words.tsv(단어 판단)·tests/typing.tsv(앱에 치는 것) + 동작 원리 테스트, 약 3초
dotnet run -c Release --project tools/Fuzz   # 자동 테스터: 문장을 만들어 계속 입력해 보고 실패를 모음 (코어를 모두 써서 3만 문장 약 1분)
.\tools\smoke-test.ps1 -Exe <HanYeong.exe>   # 실제 키 입력 테스트, 테스트 창 + 메모장 (약 1분간 키보드·마우스 사용 금지).
                                             # 실제 IME·앱에서만 보이는 문제용. 전체는 릴리스 직전에, 실패한 단계만 -Only '단계 이름'으로
python tools\build_dictionaries.py <폴더>     # 단어 빈도 데이터 다시 만들기
python tools\build_names.py <폴더>            # 이름 목록 다시 만들기
```

구조: `src/HanYeong.Core` (한글 조합·분해, 자동 판단, 단어 데이터) · `src/HanYeong` (후킹, IME 제어, 트레이·설정) · `tests/`
